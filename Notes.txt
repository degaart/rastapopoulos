# Checkpoints

## Checkpoint 1

One single-thread user task that calls gettid().

- Draft fault handlers
- Draft syscall handlers
- Draft process control block and thread control block
- Basic VMM
   - Dummy alloc-only PMM
   - Page directory & page table manipulation routines
   - Address space manager
- Rough first program loader
   - Setup task
   - Setup thread
   - Init mem regions
   - Craft register values
   - Craft kernel stack contents
   - Set control regs

## Checkpoint 2

Two threads can context-switch back and forth. Either fork() or exec() works.

## Checkpoint 3

Half of syscalls and exception handlers work.

## Checkpoint 4

Rough version of all syscalls.

## Checkpoint 5

All code written.

- Kernel boots
- Shell running
- Can run commands
